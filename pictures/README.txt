這個資料夾放遊戲裡「可以上色的圖」。

換圖方法：直接在 GitHub 上傳或取代這裡的圖片就好，Cloudflare 會自動更新網站。
- 檔名要用數字連續編號：1.png、2.png、3.png ...（也可以用 .jpg .jpeg .webp .gif）
- 要換掉某一張：用同樣的檔名上傳覆蓋
- 要新增：用下一個號碼（例如現在有 9 張，就放 10.png）
- 要刪除：刪掉檔案後，後面的號碼要往前補上（遊戲遇到第一個缺號就會停止讀取）
- 最好是「白底黑線條」的圖（或透明底的線條圖）；圖片裡越黑的地方會變成線條，白色／透明的地方就是可以上色的空白
- 圖片會自動放進正方形畫布，建議用 800～1500 像素的方形圖
